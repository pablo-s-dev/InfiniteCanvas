# Conventional Commit Plan

Use granular commits that keep the standalone app and Memory Copilot embed testable.

1. `docs: document canvas architecture and embed contract`
2. `refactor: add standalone app shell around canvas`
3. `feat: add local drawing library foundation`
4. `feat: add versioned canvas document schema`
5. `feat: add composite drawing tag model`
6. `feat: add google drive app data sync adapter`
7. `feat: add iconify icon adapter for web`
8. `chore: start 1.1.0 alpha versioning`
9. `test: add document and repository coverage`
10. `feat: add canvas document persistence wiring`
11. `feat: add export and share workflows`
12. `feat: add selection clipboard actions`
13. `refactor: make canvas item schema the only document format`

Do not combine Memory Copilot protocol changes with unrelated UI or storage changes.
